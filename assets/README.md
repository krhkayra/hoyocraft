# Game artwork

`genshin-impact.webp` is the unchanged file downloaded on 2026-11-10 from the
user-provided [Genshin Impact image URL](https://static.wikia.nocookie.net/gensin-impact/images/8/80/Genshin_Impact.png/revision/latest/scale-to-width-down/1000?cb=20240331104358).

Although the source URL ends in `.png`, the server supplied WebP image data;
the local filename uses the actual format: 1000 × 1000 pixels, RGB, without transparency. The image is the
Paimon game icon with the HoYoverse wordmark. No conversion, recoloring or other
modification was performed.

This artwork identifies the game in the launcher; it is not the HoYoCraft
application/window icon. The source repository's software license does not
relicense third-party game artwork; its rights remain with the respective
rights holders.
